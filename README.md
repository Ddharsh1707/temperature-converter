# Temperature Converter

Converts between Celsius, Fahrenheit and Kelvin as you type.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/temperature-converter.git
```
